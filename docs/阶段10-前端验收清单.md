## 5. 四类失败态

| 失败态 | 触发方式 | 界面表现 |
|---|---|---|
| 401 无 token | 清掉 localStorage 后访问 `#/chat` | 路由守卫跳 `#/login`；若在页面内被 401（token 被换），`client.ts` 广播事件 → session store 清状态 → 跳登录并提示「登录已失效（token 无效或已更换），请重新粘贴」 |
| 409 SCOPE_EMPTY | 用 outsider token 提问（租户内候选 ∩ ACL = 空） | 输入框上方红条「这个范围里没有可检索的文档。换一个范围，或在「选文档」里勾几份已就绪的文档。」 |
| 404 会话不存在 | 手改地址到 `#/chat/999999` | 提示 + 自动回到 `#/chat` |
| 证据不足 | 问语料外的问题（如「毛利率是多少」在部分语料下） | 答案区显示「证据不足：检索到的内容里没有能支撑这个问题的信息。」+ 警告标签；不发引用卡 |

> 后两条的后端语义分别由 `RestAuthContractTest`（6 例）与 `ConversationE2ETest` 第 4 例兜住；本清单验证的是「界面把话说清楚了」。
