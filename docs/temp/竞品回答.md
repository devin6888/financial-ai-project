# 用户提问：

分析下2024年和2025年的营业总收入，然后看下是什么原因导致的

## 三、增长原因分析

### 1. 证券业务是核心驱动力（贡献主要增量）

2025年证券服务收入125.35亿元，同比增长47.59%，占总收入比重从73.19%提升至78.02%。

**原因：**

- 报告期内资本市场景气度回升，东方财富证券**经纪业务股基交易额达38.46万亿元**（2024年为24.24万亿元，增幅约58.7%）
- 获批上市证券做市业务资质，推进北交所、科创板股票做市业务，拓宽服务覆盖面
- 手续费及佣金净收入从2024年的61.13亿元增至2025年的91.00亿元，**增长48.85%**
- 利息净收入从2024年的23.81亿元增至2025年的34.35亿元，**增长44.29%**（主要来自融出资金利息收入增长）

### 2. 金融电子商务服务（基金销售）稳步增长

2025年金融电子商务服务收入31.82亿元，同比增长11.99%。

**原因：**

- 天天基金基金销售额从2024年的18,811.70亿元增至2025年的26,055.84亿元
- 非货币市场公募基金保有规模从6,113.62亿元增至7,701.33亿元
- 权益类基金保有规模从3,823.76亿元增至4,456.17亿元
- 受益于2025年居民资产配置权益化趋势增强、公募基金规模扩容（37.71万亿元，较年初增长14.86%）

### 3. 金融数据服务及其他业务增长

- 金融数据服务收入2.40亿元，同比增长25.18%
- 其他收入1.10亿元，同比增长42.03%

### 4. 宏观与政策环境支撑

- 2025年GDP达140.2万亿元，增长5.0%；居民人均可支配收入43,377元，名义增长5.0%
- 中国证监会发布《推动公募基金高质量发展行动方案》等政策，引导行业从"重规模"向"重投资者回报"转型
- 个人养老金制度全国推广，存续个人养老金基金规模从91.41亿元增至185.70亿元，增长约103%

------

## 四、总结

2025年营业总收入增长38.46%，**核心驱动来自证券业务（+47.59%）**，主要受益于资本市场行情回暖带来的经纪、两融、做市等业务放量；**金融电子商务服务（+11.99%）** 则受基金销售规模扩大和保有量提升支撑。整体呈现"证券业务为主引擎、基金销售为稳定器"的增长格局，与2025年资本市场活跃度提升、居民财富管理需求释放的宏观背景高度吻合。
